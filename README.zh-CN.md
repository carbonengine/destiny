# Destiny

[English](./README.md) | [简体中文](./README.zh-CN.md)

> 知名太空飞船题材 MMO《EVE Online》的核心游戏世界模拟引擎。

## 构建

构建本库需要能够访问 Perforce,因为我们的部分依赖存放在那里。构建脚本要求设置 `CCP_EVE_PERFORCE_BRANCH_PATH` 环境变量,使其指向对应的 Perforce 分支路径。

完成上述设置后,即可使用常规的 CMake 工作流进行构建。
